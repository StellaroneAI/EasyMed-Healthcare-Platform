# EasyMedPro - AI-Powered Healthcare Platform

EasyMedPro is a React + TypeScript + Vite application for digital healthcare workflows, including patient, doctor, ASHA worker, and admin experiences.

## Features

- Multi-role dashboards (patient, ASHA, doctor, admin)
- OTP-based authentication flow
- Multilingual UI support
- Voice assistant interfaces
- ABHA integration surface for healthcare identity workflows

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the app:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Environment Setup

1. Copy `.env.example` to `.env`.
2. Provide values for required keys.
3. Do not commit real credentials or secrets.

## Deployment

The repository includes `vercel.json` configured for Vite output (`dist`).
